# 🚨 Operation Blackout Recovery

## 📖 Project Overview

Operation Blackout Recovery is a Linux file management and system administration project that simulates a real-world cyber attack recovery scenario. The goal of this project is to practice Linux commands, file management, log investigation, permissions, backup, recovery, and Git version control.

---

## 🎯 Scenario

A company's production server was affected by a cyber attack.

As a Junior Linux Administrator, my responsibilities were:

- Organize company departments
- Create and manage employee records
- Investigate system logs
- Identify security issues
- Backup critical data
- Quarantine corrupted files
- Secure sensitive files using Linux permissions
- Generate a recovery report
- Push the completed project to GitHub
